管理员登录

首次登录使用本机私有配置目录中的 bootstrap-token，15 分钟内有效。没有公共默认密码。

设置管理员密码

请设置至少 16 个字符的独立管理密码。设置后会退出所有会话。

配置无法读取

未用默认值覆盖原文件。可明确恢复最近已知备份；原文件会另存保留，恢复后还需要应用。

修订与运行状态

重新加载会丢弃未保存的草稿。连接测试只校验草稿，不修改线上配置。

家庭与 Relay

代理连接与 TLS

家庭 sing-box 为必选组件；不允许绕过代理直连 frps。实际 UUID 和 token 不通过读取接口返回，留空保留，勾选清除会在保存时检查必需依赖。

TLS 文件导入

导入到本端受控私有目录。私钥不会通过读取或导出接口返回；导入后在上面的下拉框选择。

Web 管理入口

Relay 默认仅监听回环；外部访问须使用 HTTPS 和管理员认证。Home 管理页默认允许家庭局域网 IP 访问，仍需登录。入口变化保存后，需要在本机重启管理服务。

应用会重启本端组件，可能中断正在进行的媒体播放；不会自动更新另一端。
